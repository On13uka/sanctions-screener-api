Add EU + UK sanctions lists via OpenSanctions (v1.1)

- Add app/opensanctions.py: FollowTheMoney JSON Lines loader for
  eu_fsf (EU Financial Sanctions Files) and gb_fcdo_sanctions
  (UK FCDO Sanctions List, which replaced the deprecated HMT/OFSI
  feed in January 2026). On-disk cache with 24h TTL under data/.
- Update app/main.py: add EU + UK sources alongside the existing
  OFAC SDN and UN Consolidated XML feeds. Response is additive over
  v1.0: ofac_matches/un_matches/matches fields are preserved;
  eu_matches, uk_matches, and per-source data_updated entries added.
  Migrate from deprecated on_event("startup") to lifespan handler.
- README: document the four lists, multi-match response shape,
  self-host vs Vercel trade-off (ephemeral FS + cold-start cost),
  and the CC BY-NC 4.0 attribution/license requirement for the
  OpenSanctions-backed EU + UK data.
- Landing page: add EU + UK feature cards, multi-list matches,
  daily refresh, and an OpenSanctions attribution FAQ entry.
- Tests: 10 pytest tests (OFAC, EU-only, clean, multi-match,
  backward compat, status, root, AKA, invalid name, threshold)
  using small fixture files, no network access. All pass.
- .gitignore: exclude the on-disk data/ cache.

Backward compatibility: the source field values "OFAC SDN" and
"UN Consolidated" are unchanged. New values are "EU Consolidated"
and "UK FCDO". Old clients reading source + match_score keep working.
